# 曲库

子文件夹名 = 子风格标签（FR-015：维护者亲手定义电台的审美范围）。

| 文件夹 | 定位 |
|---|---|
| `game-bgm/` | 游戏原声与气质相近的纯音乐 |
| `cafe/` | 咖啡厅音乐 |
| `vocal-soft/` | 歌词存在感低、整体气质相符的人声歌曲 |
| `night-quiet/` | 深夜向的安静氛围 |

用法：

1. 把音频文件（mp3 / flac / ogg / m4a）放进对应子文件夹；需要新的子风格就建新文件夹（文件夹名即新标签）。
2. 运行扫描命令入库（P1 提供 `pnpm scan`，读取元数据写 SQLite）。
3. 首版目标：每个子风格 15~20 首，共 60~100 首。

音频文件不进 git（根 .gitignore 已排除），只有目录结构被跟踪。
