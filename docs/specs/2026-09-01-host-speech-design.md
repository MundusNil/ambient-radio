# 梦可说话设计：自由主播 + 酒馆式装配

- 状态：待维护者审文档，未开工
- 日期：2026-09-01
- 姊妹：`docs/product-requirements.md`、`docs/technical-design.md`、`config/persona.md`
- 灵感：SillyTavern 的 prompt 装配（角色卡 / 世界书 / 对话史 / 示例），只借结构，不搬代码（AGPL-3.0）
- 不改：D1–D9

## 1. 问题

已播出串场几乎同一骨架：时段起兴 → 比喻（光、杯子、温水）→ 对人祝福收束。

根因不是 DeepSeek 单独造成的，是装配在逼她写小品：

- 每次生成都是人生第一次开口：prompt 里没有她自己刚说过的话
- 作品知识几乎为零：曲库全是 VA-11，只注入标题 + 文件夹名 `va11halla`，`artist` 全空
- `persona.md` 与 FR-037 写成「不确定的背景宁可不提」，模型只会谈感受
- `interlude.seeds` 明文教「画面、气味、窗外的光」
- 时段放在 user 第一行（「清晨与上午，微亮，清透」）
- 字数下限 40 + 「请播一段节目内容」→ 凑满就靠比喻和「慢慢来」
- 仓库没有网页搜索；现场搜也不是本设计的路径

主播应当很自由：趁氛围闲聊，接上一句，可以讲剧情和梗，不必跟着切歌走。不是许可证（必须命中 X 才能说 Y）。

## 2. 从酒馆学什么

酒馆是 prompt 装配机，不是角色许可引擎。默认主指令只有一句：写这个人的下一句。

学这四件：

1. **主指令短。** 写梦可的下一句。她在直播，音乐在响。
2. **人格和世界分开。** `persona.md` 只做人；VA-11 等作品放世界书。
3. **她自己最近几句当作对话史**，原样放进 prompt。这是续聊的全部机制。
4. **几条真正像她的口播当示例**（`mes_example`）。世界书按她刚说的话和正在响的歌注入：聊到就给燃料，不聊到不硬塞题目。

不学：递归扫描、向量匹配、regex key、群聊、角色卡市场、联网搜索扩展、上百个旋钮。

酒馆文档里三条特别有用：

- 模型从示例和第一条学语气，比从说明书学更狠
- 对话史一长，system prompt 几乎变成「很久以前的设定」；越靠近生成底部的指令越狠
- 模型更听「要做什么」，不听一长串「不要」

## 3. 每次开口看见什么（三明治）

越靠后权重越大。core 零 IO 不变：文件由 `apps/station` 读入，和现在的 persona 一样交给 producer。

```
主指令（短）
persona.md
世界书相关条目（词典，不是本题）
示例口播
—— 以上像设定 ——
她最近 2–4 句已播口播（对话史，主记忆）
房间：正在响的曲名 / 文件夹（氛围，不是题目）
留言（若有）
L1 记忆（若有）
最后一句：接着说就好
```

切歌不触发生成，也不改「本轮题目」。定时开口的节奏仍由节目引擎决定。

没有用户消息时，对话史 + 房间就是酒馆里「现在发生了什么」的位置。

## 4. 文件

维护者所有，和 `persona.md` 同一纪律。音频仍不进 git；这些是文本，进 git。

```
config/persona.md                      # L0，只做人，不写作品百科
config/speech-examples.md              # 口吻样本（跨作品）
config/library/<style>/lore.md         # 该作品的世界书正文
config/library/<style>/tracks.md       # 曲名 → 一句核实过的备注（场景、情绪、可提的剧情）
```

没有 `lore.md` 的文件夹照常播，只是她没有该作品的设定燃料。不因此禁止闲聊。

### 4.1 世界书是词典

条目必须能单独成立。扫描她刚说的话、曲名、文件夹名；命中才注入正文。没有命中不占位置，也**不禁止**她聊别的。

今晚还在 VA-11 这条线上时，即使已经在放别的风格，VA-11 的书仍可留在手边，好把剧情往下聊。这是燃料跟随对话，不是「切歌必须换题」。

`tracks.md` 一行一条，例如：

```
Last Call | 打烊点。Jill 收到前女友来信的那场也可以挂在类似的夜上。
Meet the Staff | 员工介绍，步子轻。
```

没写的绑定不要当事实喊（别撒谎）。没写不等于不准开口。

社区梗、场景、剧情：维护者审过写进 lore / tracks。不现场搜索。

### 4.2 示例是样子，不是立法

写连续几拍，半截、具体、可以讲剧情、可以完全不提歌。不要写反面教材清单当宪法。

「清晨的光 / 像一杯 / 希望你慢慢来」若再出现，改示例和对话史里的错句，不要加第十条禁令。

## 5. 她可以怎样说话

自由，包括：

- 接上一句，把一条线慢慢往下聊（含 VA-11 剧情）
- 「我过到 Jill 收信的时候就是这首。那真是一段伤心的回忆。」——作品记忆，可以
- 完全不提正在放的歌
- 切了歌仍把上一句说完
- 聊有的没的、梗、观察、酒吧、完全不相干的话
- 一句就停，或偶尔说长一点；不设字数门禁

音乐是房间氛围，不是旁白任务。真人主播趁氛围闲聊，不是切一首解说一首。

## 6. 真正剩下的硬边

产品边，不是说话警察：

- D1：一条公共时间线；不点名听众；不编「咱们一起过关」
- D2：LLM 不选歌
- D4：无脸；不把本产品改成 Nero 数字人直播
- 不编童年、打工、在格莱德活过（那是人生）；作品记忆可以
- 不把没发生过的节目当回忆（FR-074）
- 内容红线仍在（CR-001–007）
- 不确定的设定不要当事实（FR-037 的「别撒谎」，不是「没卡片不准说」）

不做：字数门禁、切歌换题状态机、只有当前曲才能讲这场、禁剧情、许可表。

模型先不换。燃料和对话史能听之后，再用同一段口播盲听换供应商（D7 仍是改配置）。

## 7. PRD / 人格口径

不改灵魂决策。说话合同放宽：

| 条 | 调整 |
|---|---|
| FR-032 | 大多数串场可以短过 10 秒；10–25 秒仍是舒适上限，不是必须填满 |
| FR-034 | 可谈当前音乐或当前作品；仍不要变成逐首报幕。**不谈正在放的歌也完全合格** |
| FR-035 | 跨段续聊、把一条作品线往下聊，都算持续主题。换题是聊天自己飘，不是播放列表下发 |
| FR-036 | 不动。世界书不是新闻天气 |
| FR-037 | 世界书 / 曲目卡里的可当事实；没写的不要编成事实。不是开口许可证 |
| persona「只谈感受，不编造曲目背景」 | 改为：有燃料就用；没有就别把猜测喊成设定。允许作品记忆口吻。不要祝福式客服收束 |

`persona.md` 待填区建议由维护者补：这个频率怎么称呼；她对游戏夜里公共空间的偏爱。不把 VA-11 百科写进 L0（作品会换，人格不换）。

技术方案 §4.3 防编造仍成立：上下文只注入维护者写过的作品事实 + 真实播出过的口播。她自由说话，不自由发明设定。

## 8. 验收（30 分钟 Vibe Check）

过：

- 不再用「清晨的光 / 像一杯 / 慢慢来」当骨架
- 后一段能接前一段，而不是重开晚会
- 切歌后可以完全不提新歌
- 聊 VA-11 时，剧情和场景绑得住（来自世界书，或明确是感受）
- 听起来像低频的闲聊，不像每句都要把事说完

不过：每段都在祝福或总结；没燃料却把不确定剧情当事实；为了「配合切歌」掐断上一句。
